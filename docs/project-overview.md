# Project Overview: Personal Portfolio & CV Website (`CV-WEB`)

## 1. Tujuan Website
Website portfolio pribadi yang menampilkan identitas, keahlian, pengalaman kerja, dan daftar project yang pernah dikerjakan. Dilengkapi dengan fitur unduh CV (PDF) langsung dari web.

## 2. Target Pengguna
- **Rekruter / Hiring Manager:** Ingin melihat skill, pengalaman, dan bukti karya dengan cepat, bersih, dan profesional.
- **Klien / Kolega:** Ingin melihat kapabilitas teknis dan cara menghubungi.

## 3. Core Value & Impression
- **First Impression:** Begitu rekruter membuka website ini, mereka langsung paham bahwa pemilik website memiliki standar tinggi dalam pengembangan web, perhatian terhadap detail, tipografi yang rapi, dan tata letak yang intentional (bukan template generik).
- **Performance & Usability:** Cepat, responsif di semua perangkat, mudah dibaca, dan aksesibel.
