# Features & Requirements: `CV-WEB`

## 1. Core Features
1. **Hero Section:**
   - Headline & Tagline yang kuat dan langsung menjelaskan keahlian utama.
   - Dual CTA: "Lihat Karya" (Anchor link ke section project) & "Unduh CV" (Direct download PDF).
2. **About Section:**
   - Ringkasan profesional dan pendekatan problem-solving.
3. **Skills & Expertise Matrix:**
   - Pengelompokan skill yang rapi (Frontend, Backend, Tools & Workflow).
4. **Experience Timeline:**
   - Riwayat pekerjaan/pengalaman dengan detail pencapaian.
5. **Selected Projects / Works:**
   - Grid project pilihan dengan screenshot/thumbnail, deskripsi singkat, tech stack badge, dan link demo/repo.
6. **Downloadable CV:**
   - Tombol unduh CV (PDF) yang responsif dan langsung mengunduh file PDF dari asset lokal.
7. **Contact & Social Links:**
   - Email, GitHub, LinkedIn, Telegram, dll.

## 2. Non-Functional Requirements
- **Design:** Intentional typography (editorial/clean sans-serif balance), refined spacing, high contrast, zero AI slop (no generic gradient blobs or fake testimonials).
- **Performance:** Fast loading, zero heavy external framework dependencies unless necessary (pure HTML/CSS/JS or lightweight vanilla setup).
- **Accessibility:** Semantic HTML tags, proper ARIA labels, keyboard navigation support.
- **Responsiveness:** Fully adaptive from mobile (320px) to ultra-wide desktop.
